3. Lombok

Lombok écrit les getters, les setters et les constructeurs. Tu ne les tapes pas.

Chapitre Lombok. Sur chaque entité : Getter, Setter, AllArgsConstructor, NoArgsConstructor.

0 sur 0

@Entity
@Getter
@Setter
@AllArgsConstructor
@NoArgsConstructor
public class Bloc {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long idBloc;
    private String nomBloc;
}

Ces quatre annotations vont sur chaque entité du TP.

Pour les entités du TP, préfère les quatre annotations ci-dessus à @Data. Cette dernière ajoute notamment toString() et equals()/hashCode() : sur des relations bidirectionnelles, elles peuvent provoquer une récursion ou des effets indésirables. @Data ne remplace pas automatiquement @AllArgsConstructor.

Si IntelliJ dit cannot find symbol getNom, Lombok n'a pas généré la méthode. Va dans Settings, Build, Compiler, Annotation Processors, et coche Enable annotation processing. Le plugin Lombok doit être installé.
