2. Entités

Une entité est une classe Java. Au démarrage, Hibernate en fait une table.

Spring Data JPA, Entités. @Entity sur la classe. @Id sur la clé. @GeneratedValue est facultatif.

0 sur 0

La plus petite entité

@Entity
public class Bloc {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long idBloc;
    private String nomBloc;
    private Long capaciteBloc;
}

@Entity est obligatoire. @Id est obligatoire. IDENTITY veut dire que MySQL choisit le numéro.

Si la clé est un String, comme idReservation, tu mets seulement @Id. Tu envoies la valeur toi-même dans le JSON.

Enum et date

@Enumerated(EnumType.STRING)
private TypeChambre typeC;

@Temporal(TemporalType.DATE)
private Date dateNaissance;

STRING enregistre le mot DOUBLE, pas le chiffre 0 ou 1.

Le nom de la colonne : une majuscule au milieu du mot devient _. idChambre devient id_chambre. typeC devient typec, parce que le C est à la fin. C'est ce qu'on a vu dans ta base tpfoyerdb.
