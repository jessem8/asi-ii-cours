6. Injection

Ta classe ne fait pas new. Spring crée les objets et les passe aux autres.

Injection des dépendances. Couplage fort : ta classe construit l'autre avec new. Couplage faible : elle demande une interface, Spring fournit l'objet.

0 sur 0

Sans injection, une classe pourrait créer une implémentation concrète avec new DaoImpl(). Elle devient alors fortement liée à cette implémentation. On ne peut pas faire new BlocRepository(), car BlocRepository est une interface.

Avec Spring, tu déclares le champ. Spring le remplit.

@Service
@AllArgsConstructor
public class BlocServiceImpl implements IBlocService {
    BlocRepository blocRepository;

    public List<Bloc> retrieveAllBlocs() {
        return blocRepository.findAll();
    }
}

@Service dit à Spring de créer cet objet. @AllArgsConstructor est le constructeur. Spring voit ce constructeur et met le repository dedans.

Le controller fait la même chose, mais son champ est l'interface IBlocService, pas la classe BlocServiceImpl.

Seulement si deux classes implémentent la même interface et que les deux ont @Service. Avec une seule classe, tu n'ajoutes ni @Qualifier ni @Primary.
