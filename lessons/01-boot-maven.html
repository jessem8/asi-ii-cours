1. Spring Boot et Maven

Cette leçon sert à créer le projet et à le lancer une fois, avant d'écrire une entité.

Introduction, puis Spring Boot et Maven. Les slides parlent de JDK 17 et d'une vieille version de Boot. Dans IntelliJ aujourd'hui, tu prends Java 21 et Spring Boot 4. C'est normal.

0 sur 0

À quoi sert Spring Boot

Sans Boot, tu installes Tomcat toi-même et tu ajoutes les jars un par un. Avec Boot, le projet démarre tout seul quand tu lances la classe principale. Le serveur est dedans.

Créer le projet dans IntelliJ

  1. File, New, Project, Spring Boot.
  2. Maven, Java, Jar, JDK 21.
  3. Group : tn.esprit. Le nom du projet est celui du sujet.
  4. Coche Spring Web, Spring Data JPA, MySQL Driver, Lombok.
  5. Après la création : File, Project Structure, SDK 21.

Spring Web écrit spring-boot-starter-webmvc dans le pom. Tu ne changes pas ce nom.

Le fichier application.properties

MAMP doit être démarré, MySQL vert, avant de lancer l'application.

spring.datasource.url=jdbc:mysql://localhost:3306/labdb?createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=<le mot de passe MySQL de MAMP>
spring.jpa.show-sql=true
spring.jpa.hibernate.ddl-auto=update
spring.jackson.deserialization.fail-on-null-for-primitives=false
server.port=8089
server.servlet.context-path=/lab

createDatabaseIfNotExist=true crée la base. update crée les tables manquantes. Il n'efface pas les anciennes colonnes. show-sql=true affiche le SQL dans la console.

Le premier lancement, sans entité, est bon quand tu lis Started et Tomcat sur le port 8089.
