Association

Attention : mappedBy indique toujours le côté inverse. En 1:N bidirectionnel, Foyer porte mappedBy tandis que Bloc porte @ManyToOne et la clé étrangère.

// Bibliotheque
@OneToMany(mappedBy = "bibliotheque")
@JsonIgnore
private Set<Livre> livres;

// Livre, le fils
@ManyToOne
private Bibliotheque bibliotheque;

idChambre devient id_chambre. typeC devient typec.

Un seul sens / deux sens

Les quatre cardinalités 1:1, 1:N, N:1, N:N admettent les deux directions. mappedBy est du côté inverse ; en 1:N bidirectionnel, la clé étrangère est gérée par @ManyToOne.

Service

@Service
@AllArgsConstructor
public class LivreServiceImpl implements ILivreService {
    LivreRepository livreRepository;

    public List<Livre> retrieveAllLivres() {
        return livreRepository.findAll();
    }

    public Livre retrieveLivre(Long livreId) {
        return livreRepository.findById(livreId).get();
    }

    public Livre addLivre(Livre livre) {
        return livreRepository.save(livre);
    }

    public void removeLivre(Long livreId) {
        livreRepository.deleteById(livreId);
    }

    public Livre modifyLivre(Livre livre) {
        return livreRepository.save(livre);
    }
}

Controller

@RestController
@AllArgsConstructor
@RequestMapping("/livre")
public class LivreRestController {
    ILivreService livreService;

    @GetMapping("/retrieve-all-livres")
    public List<Livre> getLivres() {
        return livreService.retrieveAllLivres();
    }

    @PostMapping("/add-livre")
    public Livre addLivre(@RequestBody Livre body) {
        return livreService.addLivre(body);
    }
}
