Mots du cours

Les mots des slides, avec une phrase simple.

MotÇa veut dire
EntitéLa classe Java qui devient une table. @Entity sur la classe, @Id sur la clé.
FilsLe côté que le professeur désigne. Dans le code, c'est le côté mappedBy.
mappedByDit : l'autre classe garde le lien. Ce côté ne crée pas sa propre clé étrangère.
Couplage fortTa classe fait new sur l'autre classe. Si l'autre change, la tienne doit changer.
Couplage faibleTa classe demande une interface. Spring fournit l'objet.
InjectionSpring passe un objet à un autre. Ici, par le constructeur de Lombok.
BeanUn objet créé par Spring. @Service en marque un.
RepositoryL'interface vide qui lit et écrit une table.
ServiceLa classe qui appelle le repository. Le controller appelle le service.
ControllerLa classe qui reçoit l'appel HTTP et renvoie le JSON.
Context pathLe morceau d'adresse juste après le port. Exemple : /tpfoyer.
Table de jointureUne table qui ne sert qu'à relier deux entités.
ddl-auto=updateCrée les tables et les colonnes qui manquent. N'efface rien.
