Par où commencer

Suis les leçons dans l'ordre du cours. Chaque leçon est courte. Les questions sont en bas de la page.

  1. Spring Boot et Maven — créer le projet et le lancer.
  2. Entités — la classe qui devient une table.
  3. Lombok — les getters sans les écrire.
  4. Associations — qui est le fils, quelle table est créée.
  5. JpaRepository — l'interface vide.
  6. Injection — Spring crée les objets, tu n'écris pas new.
  7. REST et Postman — l'adresse et les cinq méthodes.

Quand les 7 leçons sont faites

Lis le plan des 60 minutes. Garde la fiche ouverte. Fais le labo 1 avec la solution visible. Puis le labo 5 sans les indices.

Le labo de demain dure 60 minutes. Il y a 3 entités reliées. Il utilise tout le cours jusqu'à REST. Pas les méthodes findBy, pas JPQL.
