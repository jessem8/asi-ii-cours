Lab 4 — Événements

Plusieurs vers un dans un seul sens, et plusieurs vers plusieurs dans les deux sens. Pas de table de jointure pour le club.

60:00

Énoncé

Travail à faire. Base eventsdb, port 8089, context path /events.

Club (idClub Long généré, nomClub, adresse).

Evenement (idEvenement Long généré, titre, dateEvent Date).

Participant (idParticipant Long généré, nom, prenom).

Un événement appartient à un club. Unidirectionnelle, depuis Evenement. Club n'a pas de collection.

Un événement accueille plusieurs participants, un participant inscrit plusieurs événements. Bidirectionnelle. Le participant est le fils.

* — 1 de Evenement vers Club, sans retour. * — * , Participant est le fils.

Checklist

Indices

Une flèche many-to-one seule ne crée pas de join table. La colonne est club_id_club.

Le nom de la join table commence par l'entité propriétaire : evenement_participants.

Tables attendues

  • club (id_club, nom_club, adresse)
  • evenement (id_evenement, titre, date_event, club_id_club)
  • participant (id_participant, nom, prenom)
  • evenement_participants (evenements_id_evenement, participants_id_participant)

MySQL n'était pas démarré quand ces pages ont été écrites. Cette liste suit la règle déjà vue dans tpfoyerdb : idChambre devient id_chambre, typeC devient typec. Les cinq projets compilent avec le JDK 21.

Solution

Même forme que le projet du cours. Tu tapes la version ci-dessous, avec le port 8089.

spring.datasource.url=jdbc:mysql://localhost:3306/eventsdb?createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=<the MAMP MySQL password>
spring.jpa.show-sql=true
spring.jpa.hibernate.ddl-auto=update
spring.jackson.deserialization.fail-on-null-for-primitives=false
server.port=8089
server.servlet.context-path=/events

package tn.esprit.events.entity;

import jakarta.persistence.*;
import lombok.*;
import java.util.Date;
import java.util.Set;

@Entity
@Getter
@Setter
@AllArgsConstructor
@NoArgsConstructor
public class Evenement {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long idEvenement;
    private String titre;
    @Temporal(TemporalType.DATE)
    private Date dateEvent;
    @ManyToOne
    private Club club;
    @ManyToMany
    private Set<Participant> participants;
}

package tn.esprit.events.service;

import lombok.AllArgsConstructor;
import org.springframework.stereotype.Service;
import tn.esprit.events.entity.Club;
import tn.esprit.events.repository.ClubRepository;

import java.util.List;

@Service
@AllArgsConstructor
public class ClubServiceImpl implements IClubService {

    ClubRepository clubRepository;

    public List<Club> retrieveAllClubs() {
        return clubRepository.findAll();
    }

    public Club retrieveClub(Long clubId) {
        return clubRepository.findById(clubId).get();
    }

    public Club addClub(Club club) {
        return clubRepository.save(club);
    }

    public void removeClub(Long clubId) {
        clubRepository.deleteById(clubId);
    }

    public Club modifyClub(Club club) {
        return clubRepository.save(club);
    }
}

@RestController
@AllArgsConstructor

    public List<Club> getClubs() {
        return clubService.retrieveAllClubs();

    // http://localhost:8089/events/club/retrieve-club/1

        return clubService.retrieveClub(id);

        return clubService.addClub(body);

        clubService.removeClub(id);
    }

        return clubService.modifyClub(body);
    }
}
