Lab 3 — Projets

Un vers un dans les deux sens, un id String, et un vers plusieurs dans un seul sens.

60:00

Énoncé

Travail à faire. Base projetsdb, port 8089, context path /projets.

Equipe (idEquipe Long généré, nomEquipe).

Projet (idProjet String, sans génération, nomProjet).

Developpeur (idDeveloppeur Long généré, nom, prenom).

Une équipe réalise un seul projet, un projet est réalisé par une seule équipe. Bidirectionnelle. Le projet est le fils.

Une équipe contient plusieurs développeurs. Unidirectionnelle, depuis Equipe.

Repository de Projet : JpaRepository avec String. Le POST envoie idProjet.

1 — 1, Projet est le fils. 1 — * dans un seul sens vers Developpeur.

Checklist

Indices

La clé étrangère projet_id_projet est sur equipe, parce que Equipe est le propriétaire du OneToOne.

Developpeur n'a aucun champ d'association.

Tables attendues

  • equipe (id_equipe, nom_equipe, projet_id_projet)
  • projet (id_projet varchar, nom_projet)
  • developpeur (id_developpeur, nom, prenom)
  • equipe_developpeurs (equipe_id_equipe, developpeurs_id_developpeur). La colonne developpeurs est la clé primaire.

MySQL n'était pas démarré quand ces pages ont été écrites. Cette liste suit la règle déjà vue dans tpfoyerdb : idChambre devient id_chambre, typeC devient typec. Les cinq projets compilent avec le JDK 21.

Postman

Equipe

POST http://localhost:8089/projets/equipe/add-equipe

{
  "idEquipe": null,
  "nomEquipe": "Exemple",
  "projet": null,
  "developpeurs": []
}

Puis GET http://localhost:8089/projets/equipe/retrieve-all-equipes, GET avec un id, PUT modify-equipe avec l'id rempli, DELETE remove-equipe/{id}.

Solution

Même forme que le projet du cours. Tu tapes la version ci-dessous, avec le port 8089.

spring.datasource.url=jdbc:mysql://localhost:3306/projetsdb?createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=<the MAMP MySQL password>
spring.jpa.show-sql=true
spring.jpa.hibernate.ddl-auto=update
spring.jackson.deserialization.fail-on-null-for-primitives=false
server.port=8089
server.servlet.context-path=/projets

package tn.esprit.projets.service;

import lombok.AllArgsConstructor;
import org.springframework.stereotype.Service;
import tn.esprit.projets.entity.Developpeur;

import java.util.List;

@Service
@AllArgsConstructor
public class DeveloppeurServiceImpl implements IDeveloppeurService {

    DeveloppeurRepository developpeurRepository;

    public List<Developpeur> retrieveAllDeveloppeurs() {
        return developpeurRepository.findAll();
    }

    public Developpeur retrieveDeveloppeur(Long developpeurId) {
        return developpeurRepository.findById(developpeurId).get();
    }

    public Developpeur addDeveloppeur(Developpeur developpeur) {
        return developpeurRepository.save(developpeur);
    }

    public void removeDeveloppeur(Long developpeurId) {
        developpeurRepository.deleteById(developpeurId);
    }

    public Developpeur modifyDeveloppeur(Developpeur developpeur) {
        return developpeurRepository.save(developpeur);
    }
}
